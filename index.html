Appendix — Sample Log

Rhythm Of A Living Thing: Interactive Sample Appendix

Presented here is every sample used in production, the technique used to manipulate it, and the evidence from the session (for some I only had bounced audio files from the MPC and rely on video footage if I managed). Expand each track to listen to the original sample, my version/interpretation, and the finished track. Search and filter tracks by production technique.

How this page works

Everything is driven by the tracks array near the bottom of the HTML file. Each track has a samples list — one entry per sample used, however many that is (some tracks have one, Track 1 has seven). Point each sample's src at a file in the media/ folder next to this HTML file.

To publish: zip this file + the media/ folder together (opens in any browser, no internet needed), or host both on a free GitHub Pages site for a shareable link.
